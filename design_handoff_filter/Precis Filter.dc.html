Behaviour
Panel state is separate from applied state: choices are a draft until Apply commits them. Cancel, backdrop click and Escape all discard. Removing a chip applies immediately — no panel needed for undo.
Scaling
Groups show five, sorted by today's count, with Show all beneath. The search field filters both groups at once, so 200 sources costs no more header space than 5.
Empty states
Counts are computed against today's items, so a facet that would return nothing reads 0 before it is clicked. A zero-result combination offers Clear filters rather than a blank page.
