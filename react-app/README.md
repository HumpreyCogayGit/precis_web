# Precis React App

This is the Vite-powered React frontend for Precis Web.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode. Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

The page reloads when you make changes.

### `npm test`

Runs the Vitest test suite. Use `npm test -- --run` for a single non-watch run.

### `npm run build`

Builds the app for production to the `dist` folder.

### Environment variables

Use `VITE_API_BASE_URL` only when the frontend should call a separate API origin. Leave it unset on Vercel so the app uses same-origin `/api/*` routes.
